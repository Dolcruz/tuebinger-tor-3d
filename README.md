# Grüßle vom Tübinger Tor

Die Reutlinger Altstadt rund ums Tübinger Tor als begehbare 3D-Postkarte im Gouache-Stil (Three.js).
Sommer, Winter und Nacht, Rundflug, Figuren die durchs Tor laufen.

Live: https://dolcruz.github.io/tuebinger-tor-3d/

## Daten

Gebäude, Gelände und Bäume stammen aus den offenen Geodaten des Landes Baden-Württemberg:
